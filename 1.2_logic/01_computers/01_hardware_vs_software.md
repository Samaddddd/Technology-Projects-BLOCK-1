# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
Hardware refers to the physical parts of a computer that you can see and touch. Examples include the keyboard, mouse, monitor, motherboard, processor, and hard drive. Each part has its own job and helps the computer work properly. For example, the keyboard is used to type, while the monitor displays information on the screen. Without hardware, a computer would not be able to function. Hardware works together with software to help us perform different tasks, such as browsing the internet, playing games, and doing schoolwork.


## Explain Software
Write **at least 50 words** explaining what software is.
Software is a set of programs and instructions that tells a computer what to do and how to perform different tasks. Unlike hardware, software cannot be physically touched because it is not a physical part of the computer. Examples of software include Microsoft Word, Google Chrome, and computer games. Software allows users to write documents, browse the internet, watch videos, and complete many other activities. Without software, computer hardware would not know what tasks to perform. Both hardware and software work together to make a computer useful.


## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
Hardware and software work together to make a computer function properly. Hardware is the physical part of a computer, while software provides the instructions that tell the hardware what to do. For example, when I use Microsoft Word to type an assignment, the software processes my actions, the keyboard allows me to type, and the monitor displays the words on the screen. Without software, the hardware would not know what to do, and without hardware, the software would have nothing to run on. Both are important for a computer to work correctly.
